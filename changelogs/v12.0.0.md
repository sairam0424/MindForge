# Changelog

## [12.0.0] — 2026-09-24 — First release aimed at real external users

MindForge's first release deliberately cut for real external users, not
just internal iteration. The major-version bump is a milestone marker for
that shift, not a signal of a breaking API/behavior change — there is none
in this release; every item below is a fix. It follows a second, independent
8-agent audit (security/STRIDE, staff-engineer code review, deps+license,
live production dry-run across all 6 supported runtimes, docs accuracy,
re-verification of the prior release's deferred backlog, test-coverage gaps,
and a full trace of the CI/CD release pipeline) run specifically to check
whether v11.9.9 was actually ready for that shift. It wasn't yet: this
release closes the 1 CRITICAL and 4 HIGH findings that audit surfaced, plus
8 MEDIUM/LOW findings judged worth fixing before this exact cutover, all
independently adversarially re-verified (10/10 confirmed, 0 refuted) before
being fixed.

### Fixed

**CRITICAL**

- `--global` install printed a fabricated "PAYLOAD MANIFEST" (216 personas,
  122 skills, etc. "active") while writing none of them — the install
  success banner counted the source package tree instead of what a global
  install actually writes (entry file, commands, subagents only, by
  design). Now prints an honest message describing exactly that.

**HIGH**

- `help.md`/`status.md`/`health.md`/`security-scan.md`'s honesty fixes from
  11.9.9 didn't reach the install banner itself: it printed "Proactive
  Semantic Intent Harvesting active" — unhedged — for a feature confirmed
  to be a genuine no-op, one line below a properly-hedged PQAS claim.
  Reworded to match. The banner's surrounding "Autonomous Enterprise
  Agentic Ecosystem" / "Sovereign Intelligence" / "Autonomous Governance &
  Self-Healing" marketing language, unbacked by anything the rest of the
  project stands behind, is gone too.
- `verification-loop.js` (one of the 8 dynamic-workflow scripts null-guarded
  in 11.9.9) could still crash with an unhandled `TypeError` if its round
  loop completed zero rounds before any guard ran. Fixed with the same
  graceful-return shape its siblings already use.
- Two real test-coverage gaps: nothing asserted the removed `godmode` skill
  stays absent, or that `--minimal` actually ships 0 persona files. Both
  covered now, each verified by deliberately breaking the real fix and
  confirming the new test catches it.

**MEDIUM**

- `bin/security/trust-boundaries.js`'s deny-class gate missed the classic
  "curl/wget a payload, chmod +x it, run it by path" dropper chain (no
  interpreter keyword in the final step, so neither existing pattern
  fired). Added a pattern for it.
- `bin/governance/config-manager.js`'s `ConfigManager.set()` was vulnerable
  to prototype pollution via a `__proto__`-shaped key — not reachable from
  any shipped call site today, but a live, shared, mutable singleton.
  Guarded, matching a pattern this codebase already uses elsewhere.
- CodeQL flagged (high severity) an incomplete regex-escape in
  `bin/utils/readiness-gate.js` once this release's own plugin-bundling fix
  (below) exposed it to scanning for the first time — only literal dots
  were escaped before building a `RegExp` from the package version string.
  Fixed to escape every regex metacharacter.
- Dependabot's unconstrained docker config silently shipped the Docker MCP
  Catalog image on `node:25-bookworm-slim`, a non-LTS release. Reverted to
  `node:22-bookworm-slim` (the CI test matrix's highest tested version) and
  added an ignore rule blocking future Node major-version bumps of the base
  image.
- `docs/PERSONAS.md`'s "Enterprise Swarm Templates" table cited 16 of 25
  persona names that don't exist — a doc artifact never regenerated after
  `swarm-templates.json`'s own dangling-reference cleanup in 11.9.9.
  Regenerated wholesale from the real file: all 49 templates, exact
  leader/members/focus values.
- The release workflow's "stable dist-tag" step has failed on 4 consecutive
  real releases (11.9.6 through 11.9.9) for an identical, root-caused
  reason: its retry budget (3 attempts × 5s) was an order of magnitude
  short of npm's own stated multi-minute propagation window, even though
  the underlying write always succeeded. Widened to 10 attempts × 15s.
- `.agent/settings.json` was missing the `instinct-capture` hook
  `.claude/settings.json` has had since before 11.9.0 — a tracked,
  documented parity gap. Mirrored the registration and, for the first
  time, bundled its dependency closure into the plugin distribution.
- Three GitHub Actions hygiene items: an `${{ }}`-into-shell interpolation
  inconsistency in `control-plane.yml`, an unused `contents: write` grant
  in `auto-pr.yml`, and an unverified `gitleaks` binary download in
  `secret-scan.yml` (now checksum-verified against the project's own
  published `checksums.txt`).
- Stale doc drift: `agent.md`'s "13+ personas" claim (two mirrors)
  corrected to 216; `docs/registry/PERSONAS.md`'s 3-release-stale version
  header and unhedged PQAS citation corrected.
